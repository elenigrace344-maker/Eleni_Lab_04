
# Eleni_Lab_04

## Lab 4 – Python Applications

This project includes two Python programs developed for Laboratory 4.

### Features

**Task 1 – Goldbach’s Conjecture**
- Reads an even number greater than 2 from the keyboard.  
- Checks if numbers are prime.  
- Displays all prime pairs `(p, q)` such that `p + q = n`.

**Task 2 – Big Number Operations**
- Reads two non‑negative integers from `numere.txt`.  
- Performs digit‑by‑digit addition and long multiplication.  
- Handles carries and leading zeros correctly.
